## A smoother everyday experience

### Desktop and hardware

- More accurate battery percentages, especially near a full charge.
- Shorter fingerprint illumination transitions with reduced glare.
- External display settings now work correctly: change resolution, position, refresh rate and rotation.
- Improved speaker audio, with each speaker playing its correct stereo channel.
- Fixed crashes when connecting a charger after closing the keyboard cover.
- Fixed the Caps Lock indicator turning off when no further keys were pressed.
- Tailscale now works reliably and retains its IP address across reboots.
- Password unlock no longer waits for an ongoing fingerprint attempt to finish.
- Added the Ubuntu boot animation.

### S Pen and Tab Companion

- Air gestures no longer trigger while the pen is near the screen.
- Fixed cases where the S Pen did not reconnect automatically.
- Pointer sensitivity can now be set up to 500.
- S Pen actions and shortcuts can now send modifier keys on their own, including Ctrl, Shift and Super.
- Prepared the updater for future kernel and Ubuntu upgrades, preserving user data and settings. Ubuntu version upgrades will use the migration backend included in the corresponding validated release.
- Added optional automatic weekly update checks and notifications.

### Updating an existing installation

See [Updating an existing installation](https://github.com/agcarbajo/ubuntu-galaxy-tab-s9-ultra#updating-an-existing-installation).

The Android app (`Dualboot-v1.1.0.apk`) and partition split ZIP (`gts9u-split.zip`) are unchanged from the previous release and are only needed for dual boot.
